# 지식의 대장간 (blacksmith)

문제를 풀며 검을 벼리는 3D 개인 복습 게임입니다. 망치를 내리칠 때마다 문제가 나오고, 맞히면 검이 강해지며 틀리면 부서질 수 있습니다. 완성한 검은 쇠창살 너머의 **망각의 서고지기**에게 바칩니다.

## 플레이

- 브라우저에서 `index.html`을 서버로 열면 됩니다. 설치는 필요 없습니다.
- 로컬 실행: `node serve.js` → http://localhost:8642

## 조작

| 키 | 동작 |
|---|---|
| E | 원석 꺼내기 |
| Space | 망치 내리치기 |
| F | 검 완성 |
| Q | 제단에 바치기 |
| 1–6 | 보기 선택 |
| H | 힌트 |

## 문제 세트

타이틀의 "문제 세트"에 한 줄에 한 문제씩 붙여 넣습니다.

```
[분류] 문제 | 보기1 | 보기2 | 보기3 | 보기4 | 정답번호 | 해설
```

틀린 문제는 오답 노트에 저장되고 다음 판에 더 자주 나옵니다.

## 기술

Three.js 0.170 (CDN), WebAudio로 만든 효과음, 절차적 텍스처. 빌드 과정 없음.
