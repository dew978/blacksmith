# 지식의 대장간 (blacksmith)

문제를 풀며 검을 벼리는 3D 개인 복습 게임입니다. 망치를 내리칠 때마다 문제가 나오고, 맞히면 검이 강해지며 틀리면 부서질 수 있습니다. 완성한 검은 쇠창살 너머의 **망각의 서고지기**에게 바칩니다.

## 이야기

시험 전날 밤, 도서관에서 잠든 당신은 **망각의 서고**의 대장간에서 눈을 뜬다. 외우다 만 것, 대충 넘긴 것, 시험이 끝나자마자 흘려버린 지식이 가라앉는 곳이다. 문은 잠겼고, 서고지기는 7일 동안 날마다 정해진 가치만큼의 지식의 검을 바치라고 한다. 처음 시작하면 프롤로그 컷씬이 나오고(클릭·Space로 넘기기, Esc로 건너뛰기), 제목 화면의 "프롤로그"로 다시 볼 수 있다.

## 플레이

- 브라우저에서 `index.html`을 서버로 열면 됩니다. 설치는 필요 없습니다.
- 로컬 실행: `node serve.js` → http://localhost:8642

## 강화

- 문제는 망치를 들기 위한 관문이다. 맞히면 한 번 두드리고, 틀리면 헛손질.
- 두드린 결과는 단계별 확률표(원작 영상 수치 참고)대로 파괴·손상(−1)·유지·성공(+1)·대성공(+2). 파괴는 +6에서 21%로 가장 높고 이후 6.5%까지 내려간다.
- 가치는 1강마다 1.5배, 최대 **+100**. 영감(정답 10번)이면 몇 초간 문제 없이 연타하고 파괴되지 않는다.
- 검 모양 16가지가 0~61강에 걸쳐 바뀌고(초반엔 2강마다), +62부터는 최종형이 점점 더 빛난다.
- 모양이 바뀔 때 금빛 돌파, +25·50·75에 번개, +100에 최종 연출.

- 검걸이에 걸어 둔 검은 모루가 비었을 때 다시 가져와 이어서 강화할 수 있다.

## 조작

대장간 안을 1인칭으로 걸어 다니며, 사물을 바라보고 상호작용합니다.

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 걷기 (Shift 달리기) |
| 마우스 | 둘러보기 (움직인 만큼 그대로 회전, OS 가속 없음) |
| E / 클릭 | 바라보는 사물과 상호작용 (원석 상자·화로·모루·제단·책장) |
| Space | 모루 앞에서 망치 내리치기 |
| F | 검 완성 |
| Esc / 이동 키 | 모루 앞에서 자리 뜨기 |
| 1–6 | 보기 선택 |
| H | 힌트 |

휴대폰에서는 왼쪽 조이스틱으로 걷고, 화면을 끌어서 둘러보고, 톡 쳐서 상호작용합니다.

## 문제 (2022 개정 교육과정)

시작하기 → 학년·학기·과목을 고르면 그 범위의 문제만 나온다. 문제는 data/q/에 학년·학기·과목별 JSON으로 들어 있다(국어·사회·과학·영어 파일마다 100~110문제, 성취기준 코드 포함). 수학은 고정 20문제에 js/mathgen.js 문제 생성기가 판마다 150문제를 새로 만들어 섞는다(12개 학기 모든 단원, 템플릿 198개).

- 초1~2: 국어, 수학
- 초3~6: 국어, 수학, 사회, 과학, 영어
- 중1~3: 사회(지리·일반사회 개념), 과학, 영어

학기 배치는 경기도교육청 2025·2026 수업-평가 계획 예시의 성취기준·단원 연결표, 출판사 단원 목차 등을 따랐고, 자료가 없는 학년(초1~2 수학, 중학교 학년 배치 등)은 일반적인 순서로 정했다. 검사: node tools/check-banks.js (문제 은행), node tools/check-mathgen.js (수학 생성기 정답 재계산)

## 내 문제 세트

타이틀의 "문제 세트"에 한 줄에 한 문제씩 붙여 넣습니다.

```
[분류] 문제 | 보기1 | 보기2 | 보기3 | 보기4 | 정답번호 | 해설
```

틀린 문제는 오답 노트에 저장되고 다음 판에 더 자주 나옵니다.

## 소리

효과음·화로 소리·배경 음악은 Stable Audio 3(로컬)로 생성해 다듬은 파일이다(audio/*.mp3). 망치 타격 5종, 파괴, 화로 루프, 발소리, 문 잠김, 천둥, 돌파, 종, 동전, 정답·오답, 서고지기, 담금질, 프롤로그 드론, 배경 음악. 파일을 못 불러오면 Web Audio 합성음으로 대신한다.

## 기술

Three.js 0.170 (CDN), WebAudio로 만든 효과음, 절차적 텍스처. 빌드 과정 없음.
