# 지식의 대장간 (blacksmith)

문제를 풀며 검을 벼리는 3D 개인 복습 게임입니다. 망치를 내리칠 때마다 문제가 나오고, 맞히면 검이 강해지며 틀리면 부서질 수 있습니다. 완성한 검은 쇠창살 너머의 **망각의 서고지기**에게 바칩니다.

## 플레이

- 브라우저에서 `index.html`을 서버로 열면 됩니다. 설치는 필요 없습니다.
- 로컬 실행: `node serve.js` → http://localhost:8642

## 강화

- 최대 **+100**. 맞히면 반드시 오르고, 오르는 폭은 +2에서 시작해 10강마다 1씩 커진다(대성공은 두 배).
- 틀리면 유지·손상·파괴 중 하나. 강할수록 파괴 확률이 높다(최대 45%).
- 검 모양 16가지가 0~77강에 걸쳐 바뀌고, +78부터는 최종형이 점점 더 빛난다.
- 모양이 바뀔 때 금빛 돌파, +25·50·75에 번개, +100에 최종 연출.

## 조작

대장간 안을 1인칭으로 걸어 다니며, 사물을 바라보고 상호작용합니다.

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 걷기 (Shift 달리기) |
| 마우스 | 둘러보기 (움직인 만큼 그대로 회전, OS 가속 없음) |
| E / 클릭 | 바라보는 사물과 상호작용 (원석 상자·화로·모루·제단·책장) |
| Space | 모루 앞에서 망치 내리치기 |
| F | 검 완성 |
| Esc / 이동 키 | 모루 앞에서 자리 뜨기 |
| 1–6 | 보기 선택 |
| H | 힌트 |

휴대폰에서는 왼쪽 조이스틱으로 걷고, 화면을 끌어서 둘러보고, 톡 쳐서 상호작용합니다.

## 문제 세트

타이틀의 "문제 세트"에 한 줄에 한 문제씩 붙여 넣습니다.

```
[분류] 문제 | 보기1 | 보기2 | 보기3 | 보기4 | 정답번호 | 해설
```

틀린 문제는 오답 노트에 저장되고 다음 판에 더 자주 나옵니다.

## 기술

Three.js 0.170 (CDN), WebAudio로 만든 효과음, 절차적 텍스처. 빌드 과정 없음.
